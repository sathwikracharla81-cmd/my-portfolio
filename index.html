Featured Engineering Projects

PROJECT 1: AMENDMENT — The Board Game That Rewrites Its Own Rules

FastAPI · Python · Gemma · Ollama

AMENDMENT is an innovative turn-based multiplayer board game where players don't just follow the rules — they propose amendments in natural English to mutate gameplay mechanics.

My Backend & Game Engine Responsibilities:

  • Deterministic Engine Design: Engineered the core state machine in Python/FastAPI that validates triggers, conditions, and effects, ensuring that approved rules execute consistently without side effects.
  • Court & LLM Contract: Decoupled the AI Court (local Gemma via Ollama) from direct game state mutation. The Court parses natural language and outputs structured rulebook JSON conforming to a strict schema.
  • Rulebook Invalidation & Immutability: Implemented safeguard rules (such as R2 immutability) preventing paradoxical or game-breaking rule proposals from corrupting game states.
  • Turn Orchestration: Managed turn-cycle events (`on_turn_start`, `on_roll`, `on_land`, `on_pass`, `on_turn_end`) and synchronized state transitions via REST API endpoints.
